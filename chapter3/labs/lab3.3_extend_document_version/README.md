# Lab 3.3 (Home) — Extend, Document & Version

**Goal:** extend the pipeline with a new output and new rules, document it, and version it with Git.

## 1 · Build
- Continue with `shop_pipeline`, or apply it to a dataset of your choice.
- Add **one new output**, e.g. `revenue_by_category.csv`.
- Add **at least three new validation rules**, including **one custom check**.
- Draw the **lineage** of your pipeline: raw files → steps → outputs.

## 2 · Document & submit
- Update the **README** and the **data dictionary** for every new column.
- **Commit** with clear messages as you go, then **push** to your own GitHub repository.
- Include your **run log** and the **lineage drawing**.

## 3 · Groups & naming
- Group members may all work and keep results in **one GitHub repository**.
- **Only one representative submits the repository link** on Moodle — list all members in the README.
- Project folder: `pipeline_yourdataset/`
